## 📘 Description
**MyTop** est un moniteur système interactif en temps réel en mode terminal (style `top`/`htop`). Il interroge dynamiquement le pseudo-système de fichiers `/proc` (`/proc/stat`, `/proc/meminfo`, `/proc/[pid]/status`) pour afficher l'utilisation des cœurs CPU, la mémoire vive, la charge système (load average) et la liste ordonnée des processus actifs.

## 🔨 Compilation & Utilisation
```bash
make
./my_top
```
